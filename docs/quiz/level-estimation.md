# 판정 규칙과 플레이 데이터 검증 — Phase 4

판정 버전: `science-evidence-v3`. 게임은 10문제·20초 규칙을 유지한다.

## 출제와 판정을 분리

첫 6문제에서는 두 정답·두 오답 단위로 목표 수준을 조절한다.
같은 수준에서 빠른 두 정답이면 두 단계, 일반 두 정답이면 한 단계 상승한다.
오답 뒤 3연속 정답 회복은 한 번 추가 상승하되 속도 상승과 합쳐 두 단계까지만 이동한다.
첫 6문제 중 5개 정답이면 7번째 문제에서 최소 중2, 6개 정답이면 중3을 확인한다.
7번째 문제를 맞히고 최근 세 문제도 정답이면 중2 이상에서 한 단계 더 도전한다.
마지막 세 문제는 도달한 확인 수준에 머물고, 같은 수준에서 연속 두 오답이면 한 단계 낮춘다.
빠른 정답과 체크포인트는 더 높은 수준을 확인하는 보조 신호이며 결과 학년 자체를 올리지 않는다.
마지막 네 문제에서는 목표 수준의 직접 정답이 없는 영역과 적용 정답이 부족한 경우를 우선 확인한다.
각 영역의 출제 수 균형을 유지하므로 한 회차에 네 영역이 2~3번씩 등장한다.
동일 수준 후보가 최근 문제뿐이면 오래된 것을 재사용하며 쉬운 문제로 바꾸지 않는다.

## 결과의 정답 근거

각 후보 수준을 별도로 평가한다. 후보 수준 또는 한 단계 아래의 문제를 근거로 사용하고,
더 높은 수준의 정답은 선수 개념의 근거로도 사용한다. 더 높은 수준의 오답만으로 낮은 수준을 부정하지 않는다.
같은 문항의 복사본은 독립적인 근거로 세지 않는다.

| 결과 | 필요한 근거 |
| --- | --- |
| 공통 | 정답 3개 이상, 서로 다른 영역 3개 이상, 성취기준 3개 이상, 근거 문항 정확도 75% 이상 |
| 초등 | 후보 수준 이상의 직접 정답 2개 이상 |
| 중학교 | 후보 수준 이상의 직접 정답이 3개 영역에 걸쳐 있고, 그중 적용 정답이 2개 이상 |
| 부족 | 임의로 가장 낮은 학년을 부여하지 않고 ‘확인 필요’ 표시 |

적용 근거는 현상 예측·자료 해석·실험 판단을 중심으로 한다.
합력·반사각 계산은 적용 문제로 포함하지만 별의 색과 온도 등 단순 사실 확인은 제외한다.
이 분류는 현재 직접 작성한 106문항에 대한 초기 편집 기준이다. 경험적 난이도 추정치가 아니다.
풀이 속도는 결과 학년에 사용하지 않는다.

## 기록 저장과 내보내기

- 최근 50회의 **완료한 도전**을 브라우저에 저장한다. 서버 자동 전송은 없다.
- 중단한 도전의 문항은 최근 출제 이력에는 남지만 완료 성적 통계에는 넣지 않는다.
- 같은 회차 ID는 중복 저장하지 않는다. 잘못된 데이터는 읽을 때 걸러낸다.
- 문항 ID는 문구·보기 집합·정답·수준·성취기준에 기반한다. 문항 수정 전후의 통계를 섞지 않는다.
- 기록에는 당시의 문항 원문과 실제 표시된 보기 순서도 남아 있어 나중에 문제은행을 수정해도 응답을 재검토할 수 있다.
- 기록 저장이 실패해도 현재 방문의 메모리 기록을 JSON으로 내려받을 수 있다.
- ‘도전 기록 지우기’는 완료 기록을 삭제하며 최근 출제 이력은 유지한다.

내보낸 JSON에는 `schemaVersion`, `currentGradingVersion`, `records`, `questionStats`가 포함된다.
각 회차에는 `gradingVersion`을 저장하므로 서로 다른 판정 규칙의 결과를 구분할 수 있다.
회차의 기록에는 문제 ID·학년 수준·영역·개념·성취기준·유형·문구·보기·정답·선택·풀이 시간·넘김·시간 초과가 들어간다.

## 문항 통계의 해석

| 통계 | 정의 |
| --- | --- |
| 출제 수 | 완료 기록에서 해당 문항이 나온 수 |
| 전체 정답률 | 정답 / 출제 수, 넘김과 시간 초과 포함 |
| 답한 경우의 정답률 | 정답 / 실제 보기를 선택한 수 |
| 풀이 시간 중앙값 | 실제 답을 선택한 응답의 중앙값; 넘김·시간 초과 제외 |
| 정답 시간 중앙값 | 정답 응답만의 시간 중앙값 |
| 보기 선택 분포 | 보기 번호가 아니라 실제 선택 문구로 집계 |

20회 미만의 문항은 ‘표본 부족’으로 표시한다. 20회 이상이어도 자동으로 검증된 난이도로 취급하지 않는다.
기록은 동일 기기의 재도전이고, 적응형 출제로 응답자 수준에 따라 문제가 선택되며,
이전에 본 문제의 기억도 영향을 주기 때문이다. 경험적 학년 진단이나 모집단 정답률을 의미하지 않는다.

## 실데이터로 다음에 할 일

1. 실제 플레이 기록을 모아 자주 틀리거나 시간을 초과하는 문항을 찾는다.
2. 긴 문구·모호한 조건·그럴듯하지 않은 오답 보기부터 검토한다.
3. 같은 사람이 반복해서 본 문항과 첫 시도 문항을 구분해 해석한다. 현재 내보내기에는 개인별 식별 정보가 없으므로 그 구분은 추가 수집 설계가 필요하다.
4. 낮은 수준과 높은 수준의 경계에서 판정이 달라지는 회차를 검토한다.
5. 충분한 독립 표본이 생긴 뒤 학년군 내 게임 수준·시간 기준을 조정한다.

현재까지는 기능 구현과 자동 시나리오 검증을 완료했다. 실제 플레이 표본을 통한 난이도 보정은 아직 하지 않았다.

## v3 회귀 검증

수학 앱의 회복 상승·7번째 체크포인트·마지막 세 문제 확인 흐름을 참조했다.
과학 앱의 네 영역 균형과 중학교 세 영역 직접 정답·적용 근거 요건은 유지한다.
6번째 문제만 틀리고 나머지를 천천히 맞히는 경로는 5·5·6·6·7·7·8·8·8·8 수준으로 출제되어 중2 근거를 얻는다.
이전 기록의 결과를 다시 쓰지 않으며 새 회차에 v3 버전을 기록한다.
첫 여섯 문항의 각 오답 위치, 빠른/느린 응답, 여러 보기 선택 경로, 포화 이력에서도 상위 도전과 근거를 검증한다.


## 힘 분야 출제 비중

영역별 최소 문항 수와 물리 보너스 슬롯을 제거했다. 난이도·최근 이력·개념 반복 조건을 통과한 후보에 힘 문항과 다른 문항이 모두 있으면 힘 그룹을 70% 확률로 선택한다. 어느 그룹의 후보가 없으면 있는 그룹에서 선택한다. 후반의 학년 판정 근거 확보 조건은 우선한다. 따라서 실제 한 판의 힘 비율은 정답 패턴과 최근 이력 등에 따라 달라지며 고정 문항 수를 보장하지 않는다.

과학 전체 학년 판정에는 기존처럼 서로 다른 영역의 근거가 필요하다. 영역별 2문항 할당과 별개로 후반에는 부족한 영역의 정답 근거를 탐색한다.
