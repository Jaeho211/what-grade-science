# 몇 학년? 과학 — 구현 계획

## 제품 목표

10문제, 문제당 20초로 끝나는 과학 도전 게임. 학습 진단보다 재미를 우선한다.
수학 앱의 React/Vite 구성, 타이머, 피드백, PWA를 재사용한다.
출제와 학년 결과는 과학 전용으로 구성한다.

| Phase | 목표 | 결과물 | 상태 |
| --- | --- | --- | --- |
| 1 | 게임 규칙과 출제 설계 | 규칙, 개념 맵, 대표 문항 24개 | 완료: 교육과정 학년 대조는 후속 검토 |
| 2 | 플레이 가능한 첫 버전 | 시작/퀴즈/결과/해설, 10문제, 20초, 기본 출제·판정 | 구현 완료: 실기기 플레이 검토 필요 |
| 3 | 문항 확장과 반복 방지 | 각 수준·영역의 문항 확장, 검증된 변형, 최근 이력 | 예정 |
| 4 | 적응형 출제와 학년 판정 고도화 | 응답 기록, 난이도 검증, 영역별 확인 출제 | 예정 |
| 5 | 시각적 재미와 출시 완성 | 문제 그림·그래프, 공유 카드, 기기별 QA | 예정 |

## Phase 1 규칙

- 초기 범위: 초3~중3. 고등 범위는 후속 확장.
- 한 회차 10문제. 문제당 20초. 건너뛰기 가능.
- 보기를 누르면 즉시 확정. 정답/오답 피드백 0.4초, 시간 초과 안내 0.8초.
- 피드백 시간은 풀이 시간에 포함하지 않는다. 앱 전환 중에는 시간이 흐른다.
- 물리·화학·생명·지구과학 네 영역은 회차마다 2~3문제씩 출제.
- 현상 예측, 원리 적용, 자료 해석, 실험 판단으로 구성. 정답 후 긴 해설은 없고 결과에서 확인.
- 문항은 직접 작성한 고정 문항. 보기 순서만 무작위. 한 회차 안의 중복은 금지.
- 24문항이므로 회차 간 반복은 가능하다. 과학적 조건을 임의로 바꾸는 자동 변형은 아직 하지 않는다.

## 출제 및 기본 판정

시작 목표는 초5 수준. 첫 6문제는 두 문제 단위로 조절한다.
둘 다 정답이면 한 단계 상승, 둘 다 오답이면 한 단계 하락한다.
두 정답이 모두 1초 이상이면서 유형별 예상 풀이 시간의 절반 이내이면 두 단계 상승한다.
빠른 오답과 1초 미만 정답에는 속도 보너스가 없다.
첫 6문제의 마지막 3문제가 정답이면 추가 한 단계 도전한다.
마지막 4문제는 확인 출제하며 연속 두 오답이면 낮춘다.
영역 균형과 중복 방지 때문에 목표 수준에 문항이 없으면 가까운 수준으로 출제한다.

결과는 출제 목표와 별도로 계산한다. 후보 학년 또는 한 단계 아래에서 얻은 근거로
최소 세 정답, 세 영역의 정답, 후보 수준 이상의 직접 정답 두 개, 근거 정확도 75% 이상이 필요하다.
더 어려운 문제의 오답만으로 낮은 수준의 이해를 부정하지 않는다.
풀이 시간은 학년 계산에 사용하지 않는다.
근거가 부족하면 임의의 초3 결과 대신 **확인 필요**를 표시하고 정답 수와 영역별 기록을 보여준다.
모든 학년 표시는 이번 게임의 잠정 결과이며 전체 과학 능력 진단이 아니다.

## Phase 3부터의 개선

1. 모든 목표 수준에서 네 영역의 문항을 충분히 확보하고 초안의 학년 배치를 검토한다.
2. 최근 출제 이력으로 재도전 반복을 줄인다. 데이터는 기기 내에 저장한다.
3. 응답과 시간 초과를 내보내 문항별 정답률·풀이 시간·오답 보기 분포를 분석한다.
4. 쉬운 암기 정답만으로 높은 결과가 나오지 않도록 원리 적용·추론 근거를 보강한다.
5. 그림과 표가 필요한 문제를 추가하되 20초 내 읽을 수 있는 정보량을 유지한다.

## 검증 범위

타이머의 중복 제출·마감 경계·시간 초과·피드백 중 정지,
24문항 데이터 구조, 보기 섞기, 모든 1,024개 정오답 조합의 게임 완주,
영역 균형, 중복 방지, 전부 오답/근거 부족/최상위 도달/속도 독립 판정을 자동 검증한다.
실제 Android·iPad 화면, 설치, 공유, 오프라인, 서비스 워커 업데이트는 출시 전 실기기 확인 대상이다.
