# 몇 학년? 과학 — 구현 계획

## 제품 목표

10문제, 문제당 20초로 끝나는 과학 도전 게임. 학습 진단보다 재미를 우선한다.
수학 앱의 React/Vite 구성, 타이머, 피드백, PWA를 재사용한다.
출제와 학년 결과는 과학 전용으로 구성한다.

| Phase | 목표 | 결과물 | 상태 |
| --- | --- | --- | --- |
| 1 | 게임 규칙과 출제 설계 | 규칙, 개념 맵, 대표 문항 24개 | 완료: Phase 3에서 공식 학년군 대조 추가 |
| 2 | 플레이 가능한 첫 버전 | 시작/퀴즈/결과/해설, 10문제, 20초, 기본 출제·판정 | 구현 완료: 실기기 플레이 검토 필요 |
| 3 | 문항 확장과 반복 방지 | 84개 직접 작성 문항, 학년군 대조, 최근 60개 이력 | 완료 |
| 4 | 적응형 출제와 학년 판정 고도화 | 기기 내 기록·내보내기·통계, 강화된 판정·확인 출제 | 구현 완료: 실데이터 난이도 검증 대기 |
| 5 | 시각적 재미와 출시 완성 | 문제 그림·그래프, 공유 카드, 기기별 QA | 구현 완료: 배포·실기기 QA 대기 |

## Phase 1 규칙

- 초기 범위: 초3~중3. 고등 범위는 후속 확장.
- 한 회차 10문제. 문제당 20초. 건너뛰기 가능.
- 보기를 누르면 즉시 확정. 정답/오답 피드백 0.4초, 시간 초과 안내 0.8초.
- 피드백 시간은 풀이 시간에 포함하지 않는다. 앱 전환 중에는 시간이 흐른다.
- 물리·화학·생명·지구과학 네 영역은 회차마다 2~3문제씩 출제.
- 현상 예측, 원리 적용, 자료 해석, 실험 판단으로 구성. 정답 후 긴 해설은 없고 결과에서 확인.
- 문항은 직접 작성한 고정 문항. 보기 순서만 무작위. 한 회차 안의 중복은 금지.
- 현재 84문항. 최근 60개 문항은 같은 수준에 새 문항이 남아 있으면 뒤로 미룬다. 후보를 모두 봤다면 가장 오래전에 본 문항을 재사용한다. 과학적 조건을 임의로 바꾸는 자동 변형은 하지 않는다.

## 출제 및 기본 판정

시작 목표는 초5 수준. 첫 6문제는 두 문제 단위로 조절한다.
둘 다 정답이면 한 단계 상승, 둘 다 오답이면 한 단계 하락한다.
두 정답이 모두 1초 이상이면서 유형별 예상 풀이 시간의 절반 이내이면 두 단계 상승한다.
빠른 오답과 1초 미만 정답에는 속도 보너스가 없다.
첫 6문제의 마지막 3문제가 정답이면 추가 한 단계 도전한다.
마지막 4문제는 확인 출제하며 연속 두 오답이면 낮춘다.
영역별 출제 수를 균형 있게 유지하면서 아직 직접 정답이 없는 영역과 부족한 적용 근거를 우선 확인한다.
영역 균형과 중복 방지 때문에 목표 수준에 문항이 없으면 가까운 수준으로 출제한다.
최근 문항을 피하려고 쉬운 문제를 내지는 않는다. 목표에 가장 가까운 후보 안에서 최근 이력을 적용한다.

결과는 출제 목표와 별도로 계산한다. 후보 학년 또는 한 단계 아래에서 얻은 근거로
최소 세 정답, 세 영역·세 성취기준의 정답, 근거 정확도 75% 이상이 필요하다.
초등 결과는 후보 수준 이상의 직접 정답 두 개가 필요하다.
중학교 결과는 후보 수준 이상의 세 영역 직접 정답과 최소 두 개의 적용 정답이 필요하다.
더 어려운 문제의 오답만으로 낮은 수준의 이해를 부정하지 않는다.
풀이 시간은 학년 계산에 사용하지 않는다.
근거가 부족하면 임의의 초3 결과 대신 **확인 필요**를 표시하고 정답 수와 영역별 기록을 보여준다.
모든 학년 표시는 이번 게임의 잠정 결과이며 전체 과학 능력 진단이 아니다.

## Phase 3 완료 사항

- 7개 수준 × 4개 영역마다 직접 작성한 3문항을 제공한다. 총 84문항.
- 모든 문항에 공식 성취기준 코드와 학년군을 연결했다. 학년군 내 게임 레벨은 잠정이다.
- 그림자는 초5~6 학년군, 기체의 정성적 압축은 초3~4 학년군, 광합성 실험은 중학교로 배치했다.
- 전구 직렬 회로는 초등에서 제외하고 닫힌 단일 회로 문항으로 교체했다.
- 판 경계의 상세 특성과 지진파 시간차 대신 판 경계 분포·암석·수권 등을 출제한다.
- 최근 본 문항 60개를 오래된 순으로 저장한다. 완료·오답 여부와 무관하게 문제를 보여줄 때 기록한다.
- 손상된 저장 데이터와 옛 문항 ID를 정리한다. 저장 실패 시 현재 방문의 메모리 이력으로 계속한다.
- 문항 순서가 바뀌어도 기록이 유지되도록 내용 기반 ID를 사용한다. 문구·보기·정답·수준·성취기준이 바뀌면 새 문항으로 취급한다.

## Phase 4 구현 완료 사항

- 중학교 결과는 세 영역의 직접 정답과 최소 두 개의 적용 정답을 요구한다.
- 단순 개념·용어 확인은 적용 근거에서 제외한다. 세 성취기준 이상을 확인한다.
- 마지막 네 문제는 부족한 영역과 적용 근거를 우선 확인한다. 풀이 시간은 결과 학년을 바꾸지 않는다.
- 완료한 도전 최근 50회를 기기에 저장한다. 중단한 도전은 성적 기록에 넣지 않는다.
- 원문 문항·섞인 보기·선택·시간·넘김·시간 초과·판정 버전을 기록한다.
- JSON 파일 내보내기, 최근 기록 목록, 문항별 정답 수와 중앙값 풀이 시간을 제공한다.
- 보기 순서가 달라도 선택한 보기의 실제 문구를 기준으로 오답 분포를 집계한다.
- 저장 오류가 있어도 메모리의 기록을 내려받을 수 있다. 도전 기록 삭제는 최근 문항 이력과 별개다.
- 실데이터는 아직 없다. 통계 표본이 적거나 같은 기기 재도전만 있는 경우 난이도를 자동 변경하지 않는다.

## 남은 검증 및 Phase 5

1. 플레이 기록을 바탕으로 같은 학년군 내 문항의 실제 난이도와 개별 학년 배치를 검증한다.
2. 문항 수를 더 늘리고 검증 가능한 조건·수치 변형을 추가한다. 같은 상황의 피상적 변형은 문항 수로 부풀리지 않는다.
3. 응답과 시간 초과를 내보내 문항별 정답률·풀이 시간·오답 보기 분포를 분석한다.
4. 쉬운 암기 정답만으로 높은 결과가 나오지 않도록 원리 적용·추론 근거를 보강한다.
5. 그림과 표가 필요한 문제를 추가하되 20초 내 읽을 수 있는 정보량을 유지한다.

## 검증 범위

타이머의 중복 제출·마감 경계·시간 초과·피드백 중 정지,
84문항 데이터 구조와 모든 수준·영역의 최소 문항 수, 보기 섞기, 모든 1,024개 정오답 조합의 게임 완주,
영역 균형, 중복 방지, 전부 오답/근거 부족/최상위 도달/속도 독립 판정·세 영역 직접 근거·적용 근거·성취기준 다양성을 자동 검증한다.
최근 이력이 비어 있거나 모든 문항을 포함하는 경우 모두 1,024가지 정오답 조합을 검증한다.
즉시 재도전의 반복 완화, 모든 후보가 최근 문항일 때의 오래된 문항 재사용, 손상된 이력·저장 실패도 검증한다.
완료 기록만 저장, 회차 중복 저장 방지, 50회 보관, 보기 순서 독립 집계, 시간 초과/넘김 분리, JSON 내보내기를 검증한다.
실제 Android·iPad 화면, 설치, 공유, 오프라인, 서비스 워커 업데이트는 출시 전 실기기 확인 대상이다.

## Phase 5 구현 완료 사항

- 기존 문장과 수치를 유지하며 5개 문항에 SVG 자료와 접근성 설명을 제공한다.
- 결과 공유 경로는 버전·학년/확인 필요·정답 수·200초 이내 시간을 검증한다.
- 친구의 결과를 시작 화면에 표시하고, Worker에서 Open Graph·Twitter 메타데이터와 PNG 카드를 제공한다.
- 카드 내려받기, 모바일 문제 화면 간격, 동작 줄이기 설정을 지원한다.
- 오프라인에서는 카드 이용 안내를 표시하며 텍스트 공유와 게임은 유지한다.
- 공유 경로·GET/HEAD·잘못된 요청·PNG 크기·SVG 접근성 테스트와 Worker 배포 dry-run을 통과했다.
- 실제 배포와 Android/iPad 공유·설치·오프라인 QA는 아직 진행하지 않았다.
