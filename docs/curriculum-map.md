# 과학 개념 맵 — 초기 초안

교육과정 자료 확인의 기준은 [NCIC 국가교육과정정보센터](https://www.ncic.re.kr/bbs/eduNotice2022/list.do)이다.
현재 각 문항을 공식 성취기준에 일대일 대조한 상태는 아니다.
`level`은 게임 내 잠정 난이도, `curriculumBand`는 검토할 학년군 초안이다.
초등 학년군 및 중학교 범위 내부의 실제 학년 배치는 교과서·교육과정 대조 후 수정한다.
공식 성취기준 코드를 임의로 부여하지 않는다.

| 영역 | 기초/관찰 | 적용/조건 비교 | 추론/관계 해석 |
| --- | --- | --- | --- |
| 물리 | 자석의 극, 그림자 | 직렬 회로 | 합력, 전압·저항·전류, 운동 에너지 |
| 화학 | 상태, 응결 | 용해와 분리, 기체 압축 | 밀도, 질량 보존과 측정 범위 |
| 생명 | 한살이, 식물 실험 | 먹이 관계, 광합성 실험 | 세포 호흡, 유전 확률 |
| 지구과학 | 물의 흐름 | 태양 높이 관측, 계절 | 판 경계, 지진파 시간차, 연주 시차 |

## 문항 검토 규칙

- 정답이 하나인지, 빠진 조건 때문에 다른 답도 가능한지 확인한다.
- 기체: 입구 밀폐, 누출 여부와 온도 조건을 적는다.
- 밀도: 평균 밀도와 물에 녹지 않는 조건을 적는다.
- 먹이 관계: 단기 예측과 다른 조건이 같다는 범위를 해설에 적는다.
- 실험: 바꿀 조건과 통제할 조건을 구분한다.
- 유전: 단일 유전자·완전 우성의 조건을 명시한다.
- 시각 자료 없는 문항은 텍스트만으로 풀 수 있도록 관측 값을 모두 제공한다.
- 오답은 학습자의 오개념을 반영하도록 Phase 3에서 개선한다. 현재 일부 쉬운 문항은 명백한 오답이 많다.

대표 문항 원본은 `src/questions.ts`이며 문항마다 개념·영역·문제 유형·학년군·난이도·해설을 포함한다.
