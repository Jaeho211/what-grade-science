# 과학 개념 맵 — Phase 3 학년군 대조

## 기준 자료와 확인 범위

- [교육부 고시 제2022-33호, 총론 및 각론 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)
- [붙임2 원문 ZIP: 별책5~14](https://www.moe.go.kr/boardCnts/fileDown.do?m=&s=moe&fileSeq=1512facbda6c234a1641ac7e9c156ca2)
- ZIP 내부 **[별책9] 과학과 교육과정.hwp**의 공통 교육과정과 성취기준 적용 시 고려 사항을 확인했다.
- 2026-10-11에 문항 84개에 사용한 77개 성취기준 코드의 존재를 원문 텍스트에서 확인했다.

`standard`는 원문에 있는 성취기준 코드, `curriculumBand`는 공식 학년군이다.
초등 3~4학년군, 초등 5~6학년군, 중학교 1~3학년 범위를 대조했다.
`level`은 학년군을 나눈 게임 내 수준이며, 공식 교육과정이 각 문항의 개별 학년과 풀이 난이도를 보증한다는 의미가 아니다.
특정 출판사의 학년별 단원 순서까지 대조한 것은 아니다. 실제 응답 기반 난이도 검증은 Phase 4에서 수행한다.
이 문서는 2022-33 고시의 과학과 본문을 기준으로 하며, 최신 모든 고시의 개정 이력 전체 검토를 완료했다고 주장하지 않는다.

## 문항 검토 규칙

- 정답이 하나인지, 빠진 조건 때문에 다른 답도 가능한지 확인한다.
- 기체의 정량 관계는 일정한 온도와 기체 양을 명시한다.
- 밀도 문항은 평균 밀도, 물에 녹지 않는 조건, 완전히 잠긴 물체의 운동을 명시한다.
- 먹이 관계는 다른 조건이 같은 단기 예측임을 명시한다.
- 실험 문항은 바꾸는 조건, 같게 하는 조건, 관측 결과를 구분한다.
- 유전 확률은 단일 유전자·완전 우성 조건을 명시한다.
- 초등 지시약 문제에 pH·중화 개념을 요구하지 않는다.
- 역학적 에너지 보존은 공기 저항을 무시하는 조건을 명시한다.
- 그림이나 표 없이도 모든 관측 값을 읽고 풀 수 있게 작성한다.

문항 원본은 `src/question-data.ts`, 타입과 메타데이터는 `src/questions.ts`에 있다.

## 힘 개념 보강 — 2026-10-11

《가르쳐주세요! 힘에 대해서》의 공개 목차를 주제 참고로 삼아 독자적인 상황·보기·해설 22문항을 추가했다. 책 본문을 복제하거나 전체 내용을 확인한 것으로 표현하지 않는다. 핵력과 과학자 생애는 제외한다.

관성, 힘에 따른 운동 변화, 중력과 만유인력의 정성적 관계, 자석의 인력, 전하 사이의 전기력, 마찰력, 부력과 아르키메데스 원리, 질량과 무게, 지레와 돌림힘의 평형, 같은 방향의 합력, 탄성력과 용수철저울, 힘·질량·가속도 관계를 보강했다.

추가 문항의 `standard`는 관련 단원의 연결 코드이다. 위의 초기 84문항 검토 기록이 새 문항의 세부 내용까지 교육과정에 직접 포함됨을 보증하지 않는다. 관성·만유인력·지레·아르키메데스 원리·F=ma는 확장 개념이며 개별 학년 배치와 경험적 난이도는 잠정이다. 특히 중3의 힘·가속도 문제는 비례 관계를 문제에 제시하고 자료 해석을 평가한다.

물리 문항이 늘어도 출제기는 영역별 출제 횟수를 먼저 균등하게 맞추므로 한 판이 물리에 편중되지 않는다. 원리 적용의 단순 회상형 대신 현상 예측·자료 해석·실험 판단으로 작성해 기존 적용 근거 판정에 연결했다.

## 힘 문제 추가 확장

힘 분야 40문항을 더 추가해 총 146문항이다. 운동의 시작·정지·방향과 모양 변화, 자석, 생활 속 마찰과 탄성, 중력, 관성, 부력, 지레, 합력, 용수철, 가속도를 다룬다. 새 문항의 수준은 게임 난이도 배치이며 공식 학년 배치를 뜻하지 않는다. 초등 수준의 확장 개념에도 관련 중학교 성취기준 코드를 연결할 수 있다. 정량 문제는 비례 관계와 필요한 조건을 명시한다. 핵력은 포함하지 않는다.
