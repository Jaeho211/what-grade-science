# 몇 학년? · 과학

10문제, 문제당 20초로 알아보는 나의 과학 나이. 초3~중3 수준의 과학 도전 게임이며
물리·화학·생명·지구과학을 골고루 출제한다.
[수학 앱](https://github.com/Jaeho211/what-grade)의 화면·타이머·PWA를 기반으로 제작했다.

## 현재 구현: Phase 1–4

- 직접 작성한 문항 84개 (7개 수준 × 4개 영역 × 3문항), 보기 무작위 배치, 한 회차 내 중복 방지
- 최근 60개 출제 이력으로 반복 완화, 같은 수준의 새 문항 우선·모두 봤다면 오래된 문항 우선
- 적응형 출제, 10문제·20초, 넘기기, 정답/오답/시간 초과 피드백
- 세 영역·세 성취기준 이상의 정답 근거; 중학교 결과는 해당 수준의 세 영역과 적용 정답 두 개를 직접 확인
- 마지막 네 문제에서 부족한 영역·적용 근거를 우선 확인; 근거가 부족하면 ‘확인 필요’
- 영역별 정답 수, 연속 정답 기록, 전체 문항 정답·해설
- 결과 텍스트 공유·복사, PWA 설치·업데이트 지원
- 최근 50회 도전 기록, JSON 내보내기, 문항별 정답률·풀이 시간·보기 선택 분포 집계

문항별 교육과정 성취기준과 학년군을 교육부 2022 개정 과학과 원문에 대조했다.
학년군 내부의 개별 학년 및 실제 풀이 난이도는 게임용 잠정 배치이며, 기록 수집과 분석 기능은 구현했으나 실제 플레이 데이터에 따른 난이도 보정은 아직 진행하지 않았다.
실제 학년이나 전체 과학 능력을 진단하지 않는다.
무제한 문항 변형, 그림 문제, 공유 링크 미리보기 카드는 후속 Phase에서 구현한다.

## 실행 및 검증

Node.js 22.12 이상 또는 지원되는 최신 LTS 사용.

```sh
npm ci
npm run dev
npm test
npm run build
```

## Cloudflare 배포

Worker 이름은 `what-grade-science`. Cloudflare Git 빌드에 연결할 때 설치 `npm ci`,
빌드 `npm run build`, 배포 `npx wrangler deploy`를 사용한다.
계정과 저장소 연결·도메인 설정은 별도다. 이 저장소에 코드를 올리는 것만으로 자동 배포가 설정되지는 않는다.

```sh
npm run deploy
```

## 주요 파일

- `src/question-data.ts`: 84개 직접 작성 문항
- `src/questions.ts`: 문항 타입, 안정적인 문항 ID와 교육과정 메타데이터
- `src/history.ts`: 최근 출제 이력 저장·정리·복구
- `src/records.ts`, `src/RecordsPanel.tsx`: 완료 기록·내보내기·통계·기록 관리
- `src/quiz.ts`: 출제·영역 균형·기본 학년 판정
- `src/App.tsx`: 시작·게임·결과·해설·공유
- `src/round-clock.ts`: 마감 시간 기준 타이머·중복 제출 방지
- `src/*.test.ts`: 게임·판정·기록·데이터·타이머 검증

브라우저 실기기 QA와 플레이 데이터 기반 난이도 검증은 아직 남아 있다.
최근 문항 ID 60개와 완료한 도전 50회가 기기에 저장된다. 완료 기록에는 문제·보기·선택·풀이 시간·넘김·시간 초과·판정 버전이 포함된다.
서버로 자동 전송하지 않는다. 사용자가 기록 파일을 내려받아 공유할 수 있다.
저장 공간을 사용할 수 없는 환경에서도 게임과 현재 방문의 기록·내보내기는 동작한다.
